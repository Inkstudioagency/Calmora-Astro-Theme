Ashtanga is a set sequence practised in the same order every time. That fixed structure is the whole point: because the shapes never change, you can stop wondering what comes next and start noticing what is actually happening. Liam counts the class in the traditional way and adapts freely for whoever is in the room.

## The primary series

Sun salutations, a standing sequence, a long seated sequence and a set finishing order. In an hour the class covers a shortened version, which keeps the shape of the practice intact without requiring ninety minutes you may not have.

## Tradition without rigidity

Postures are modified whenever modification is the sensible thing. Liam is far more interested in you practising for the next twenty years than in you achieving any particular shape this month.

### Worth knowing

- The sequence is the same every week, so it becomes familiar quickly.
- It is a strong practice; expect to sweat.
- Breath is counted out loud, which helps enormously.
- Jumping is optional and stepping is not a lesser version.
- The finishing sequence and rest are never cut short.

Best approached with some flow experience behind you. If you are curious but unsure, come and watch the first ten minutes, then join in.
